v7.2.0 · 2026-10-09
🗺️
v7.2.0 — facts have shape, code lives where the agent already is, and a paused phase finally waits on itself. 7.1.0 put a door on the code map, but the new door answered in the same shapes the old blind refusal did. Now --fact-subjects reaches facts at every step (plan, cook, fix, review), a symbol's blast radius reaches a path-scoped fact as the file it lives in, a paused phase blocks every phase downstream of it instead of being bridged around, and a phase that already passed answers phase_passed rather than asking for work on disk. Full notes: CHANGELOG.md → [7.2.0].v7.2.0 — fact có hình dạng, code nằm đúng nơi agent đang ở, và phase bị pause cuối cùng cũng tự chờ. 7.1.0 mở cửa cho bản đồ code, nhưng cửa mới vẫn trả lời cùng hình với lời từ chối mù cũ. Nay --fact-subjects với tới fact ở mọi bước (plan, cook, fix, review), bán kính nổ của một symbol chạm tới fact theo đường-dẫn đúng file nó sống, phase bị pause chặn mọi phase hạ lưu thay vì bị cầu vòng nối qua, và phase đã xong trả lời phase_passed thay vì hỏi xin việc đã có trên đĩa. Ghi chú đầy đủ: CHANGELOG.md → [7.2.0].

Asking is the feature, not a nag. Writing codemap.yaml changes the user's repo, so it is the user's call — the offer rides exit 10 with an ask_user block, keeps the step's own answer whole in deferred, never masks a broken (2) or refused (3) step, and stays silent in an unattended session. Declining lasts the session; a later session asks again.Hỏi là tính năng, không phải làm phiền. Ghi codemap.yaml là đổi repo của user, nên quyền quyết thuộc user — lời mời đi cùng exit 10 và khối ask_user, giữ nguyên câu trả lời thật của bước trong deferred, không bao giờ che bước hỏng (2) hay bị từ chối (3), và im lặng khi không có người ở terminal. Từ chối có hiệu lực trong phiên; phiên sau hỏi lại.
